# مود المرافق (Companion)

هذا المستودع يحتوي مواصفات ميزة جديدة لمود ماينكرافت حسب الفكرة المطلوبة.

## الفكرة
إضافة **مرافق (NPC)** يشبه ستيف، يمكن ترويضه ويقاتل مع اللاعب، مع نظام صحة وجرد (Inventory) وسلوكيات متابعة/حراسة.

## المتطلبات الوظيفية

### 1) الترويض
- يمكن ترويض المرافق باستخدام **زمرد (Emerald)**.
- بعد الترويض يصبح تابعًا للاعب الذي روّضه.

### 2) الصحة والعلاج
- صحة المرافق تكون مساوية لصحة اللاعب الأساسية.
- يتعالج عندما يأكل أي نوع من:
  - اللحم المشوي (Steak)
  - الدجاج المشوي
  - لحم الخنزير المشوي
  - لحم الضأن المشوي
  - لحم الأرنب المطبوخ

### 3) الجرد (Inventory)
- يمتلك المرافق جردًا بسعة **32 خانة**.
- يمكن للاعب فتح جرد المرافق وإعطاؤه/أخذ العناصر.

### 4) الدروع
- يمكن تجهيز المرافق بدرع.
- القطع المدعومة: خوذة، صدرية، بنطال، حذاء.

### 5) أوضاع السلوك
- **وضع المتابعة**: يتبع اللاعب.
- **وضع الحراسة**: يبقى في مكانه ويحرس ضمن نطاق **6 بلوكات**.

### 6) الندرة والظهور
- المرافق نادر نسبيًا.
- يظهر في القرى بنسبة تقريبية **36%** عند التوليد (Spawn Chance).

### 7) بيضة الاستدعاء في الكريتف
- يتوفر للمرافق **Spawn Egg** مخصص في طور **Creative**.
- يمكن للاعب استدعاؤه مباشرة باستخدام البيضة بدون انتظار الظهور الطبيعي.

## ملاحظات تنفيذية مقترحة
- إضافة كيان جديد (CompanionEntity) مع مالك (Owner UUID).
- تخزين الجرد وحالة السلوك في NBT.
- أوامر تفاعل:
  - نقر بالزمرد للترويض.
  - نقر يمين للتبديل بين متابعة/حراسة.
  - واجهة بسيطة لفتح جرده.

## معايير قبول (Acceptance Criteria)
- عند نجاح الترويض بالزمرد، يرتبط الكيان باللاعب.
- عند إعطائه لحمًا مشويًا، تزداد صحته بشكل صحيح.
- يمكن وضع/إزالة عناصر في 32 خانة دون فقدان بيانات بعد إعادة الدخول للعالم.
- يلتزم بسلوك المتابعة والحراسة ضمن 6 بلوكات كما هو متوقع.
- الظهور في القرى يطابق النسبة المستهدفة تقريبًا عبر عدة تجارب.
- في طور الكريتف، يمكن استدعاء المرافق بنجاح عبر Spawn Egg الخاص به.
